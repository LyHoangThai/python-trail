# Python Trail optional file workspace

The main student experience is at http://localhost:8765/learn, with lessons, code, output and turn-in on one page. Parents use http://localhost:8765/parent.

For optional VS Code work, open this folder and choose **Dev Containers: Reopen in Container**. Each [numbered lesson folder](lessons/README.md) contains its instructions, assignment.py and lesson identity. Save assignment.py and run **Tasks: Run Test Task → Trail: Turn in assignment**.

The terminal confirms a saved submission ID. Each attempt appears in parent history with its source, output, feedback and changes. Browser drafts and these assignment files are separate, but submit to the same history. Ctrl+Shift+B runs a file without submitting; playground.py supports interactive terminal input.
