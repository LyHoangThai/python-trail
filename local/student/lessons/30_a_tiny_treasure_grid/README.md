# 30 · A tiny treasure grid

**Topic:** Nested lists · **Chapter:** 1

A list can hold other lists, like rows in a treasure map. `grid[row][column]` first chooses a row, then an item in that row. Counting starts at zero.

## Your assignment

Print grid[row][column]. With row 1 and column 0, the treasure is key.

The matching lesson number on the website is **30**. Its saved file is **assignment.py**. Use the browser simulator for PLC exercises.

## What this lesson checks

- Use nested list indexing with row and column.

Expected output:

```text
key
```
