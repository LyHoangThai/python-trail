# 02 · A tiny postcard

**Topic:** Printing · **Chapter:** 1

Python runs instructions from top to bottom. Each `print()` starts a new line.

## Your assignment

Print My name is Python on the first line and Let’s explore! on the second. Use a straight apostrophe in Let's.

Edit **assignment.py** in this folder. The matching lesson number on the website is **02**.

Expected output:

```text
My name is Python
Let's explore!
```
