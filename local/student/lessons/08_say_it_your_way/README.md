# 08 · Say it your way

**Topic:** F-strings · **Chapter:** 2

An f-string inserts a variable into text: `f"Hi, {name}!"`. The f before the opening quote matters.

## Your assignment

Use name in an f-string to print Hello, Pip!

Edit **assignment.py** in this folder. The matching lesson number on the website is **08**.

## What this lesson checks

- Print an f-string that inserts the name variable with {name}.
- The greeting must work when name changes.

Expected output:

```text
Hello, Pip!
```
