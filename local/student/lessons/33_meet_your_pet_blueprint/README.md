# 33 · Meet your pet blueprint

**Topic:** Classes · **Chapter:** 1

A class is a blueprint. An object is one thing made from it. A method is a function on that object; `self` means “this particular pet.” Calling pet.speak() asks that pet to do its job.

## Your assignment

Define class Pet with speak(self) that prints Hi, friend!. Make pet = Pet() and call pet.speak().

Edit **assignment.py** in this folder. The matching lesson number on the website is **33**.

## What this lesson checks

- Define class Pet and its speak method.
- Create a Pet object and call its speak method.

Expected output:

```text
Hi, friend!
```
