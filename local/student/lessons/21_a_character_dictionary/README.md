# 21 · A character dictionary

**Topic:** Dictionaries · **Chapter:** 5

A dictionary stores values under keys. For example, hero = {"name": "Pip"}. Use hero["name"] to read a value.

## Your assignment

Create hero with name Pip and level 1. Print the name, then the level on separate lines.

Edit **assignment.py** in this folder. The matching lesson number on the website is **21**.

## What this lesson checks

- Create the hero dictionary and read its name and level keys.

Expected output:

```text
Pip
1
```
