# 18 · Backpack inventory

**Topic:** Lists · **Chapter:** 4

A list stores several items in square brackets. A loop can visit each item: `for item in backpack:`.

## Your assignment

Loop through backpack and print each item on a separate line.

Edit **assignment.py** in this folder. The matching lesson number on the website is **18**.

## What this lesson checks

- Loop through the backpack list and print its actual items.

Expected output:

```text
map
snack
torch
```
