# 05 · Launch countdown

**Topic:** Printing · **Chapter:** 1

Mix text and numbers in separate print statements to build a little rocket launch sequence.

## Your assignment

Print 3, 2, 1, and Liftoff! on four separate lines.

Edit **assignment.py** in this folder. The matching lesson number on the website is **05**.

## What this lesson checks

- Print the launch sequence in order.

Expected output:

```text
3
2
1
Liftoff!
```
