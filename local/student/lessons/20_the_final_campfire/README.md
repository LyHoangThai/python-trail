## Your assignment

Define welcome(name) to print Welcome, NAME! and loop through explorers to welcome all three in order.

Edit **assignment.py** in this folder. The matching lesson number on the website is **20**.

Expected output:

```text
Welcome, Pip!
Welcome, Nova!
Welcome, Ash!
```
