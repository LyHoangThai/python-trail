# 09 · Sharing snacks

**Topic:** Arithmetic · **Chapter:** 2

`//` divides and rounds down. `%` gives the remainder. For example, `7 % 3` is 1.

## Your assignment

Print how many snacks each friend gets (4), then how many are left (1). Use // and %.

Edit **assignment.py** in this folder. The matching lesson number on the website is **09**.

## What this lesson checks

- Calculate shares with // and leftovers with %.
- Use the snacks and friends variables.

Expected output:

```text
4
1
```
