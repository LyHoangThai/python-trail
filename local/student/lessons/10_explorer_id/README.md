# 10 · Explorer ID

**Topic:** Variables · **Chapter:** 2

Combine variables and f-strings to make a character card. You can use more than one variable in an f-string.

## Your assignment

Print Explorer: Pip and Level: 1 on separate lines using the variables.

The matching lesson number on the website is **10**. Its saved file is **assignment.py**. Use the browser simulator for PLC exercises.

## What this lesson checks

- Use name and level in the printed character card.
- Both values must update when the variables change.

Expected output:

```text
Explorer: Pip
Level: 1
```

## Learn and turn in through the browser

Open http://localhost:8765/lessons/10 for this lesson's instructions, code editor and output on one screen. Your browser draft saves automatically on this computer.

3. Click **Turn in assignment** when ready. It saves the code version, checks it, and gives you a submission ID.

Parents can review the history at http://localhost:8765/parent and open any attempt to see its source, result, output and changes from the previous attempt.
