# 29 · Pack one more snack

**Topic:** Growing lists · **Chapter:** 1

Your list is a backpack. `backpack.append(item)` puts one new item at the end. It changes the list and returns None, so print the backpack afterward rather than printing append() itself.

## Your assignment

Append snack to backpack, then print every item on its own line. Start with map and add apple.

Edit **assignment.py** in this folder. The matching lesson number on the website is **29**.

## What this lesson checks

- Use append() to add snack to backpack.
- Loop over the updated backpack.

Expected output:

```text
map
apple
```
