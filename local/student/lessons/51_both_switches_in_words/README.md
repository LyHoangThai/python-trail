# 51 · Both switches, in words

**Topic:** Structured Text · **Chapter:** 2

AND in Structured Text is the same idea as two ladder contacts in series. A BOOL value is TRUE or FALSE.

## Your assignment

Assign SW1 AND SW2 to LAMP so both switches must be ON.

The matching lesson number on the website is **51**. Its saved file is **assignment.st**. Use the browser simulator for PLC exercises.

## What this lesson checks

- Test all four combinations of SW1 and SW2.
- Use the contact or Structured Text idea described in the assignment.

Expected output:

```text
Only both switches ON → LAMP ON
```
