# 19 · A reusable spell

**Topic:** Functions · **Chapter:** 4

A function packages instructions under a name. Define one with `def cheer():`, then call it with `cheer()`.

## Your assignment

Define cheer() to print You can do this!, then call it twice.

The matching lesson number on the website is **19**. Its saved file is **assignment.py**. Use the browser simulator for PLC exercises.

## What this lesson checks

- Define cheer() with its print instruction, then call it twice.

Expected output:

```text
You can do this!
You can do this!
```
