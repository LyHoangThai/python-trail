YOUR REAL CODING WORKSPACE

The playground is VS Code.

  1. Open the student folder in VS Code.
  2. Choose Dev Containers: Reopen in Container from the Command Palette.
  3. Open a file in quests/, read its mission, and edit the code.
  4. Save. Choose Tasks: Run Test Task → Trail: Check current quest.
  5. Read the feedback in the terminal; this dashboard refreshes automatically.

For free play, open playground.py and press Ctrl+Shift+B to run it. input() works in the terminal. To mark a quest as current before submitting, run “Trail: Start current quest”. The regular Python Run button runs your file but doesn’t grade it.
