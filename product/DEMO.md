# Five-minute product demo

Start with a fresh sample installation. Demo turn-ins are real saved attempts in this sample database.

1. **Choose a subject.** Open http://localhost:8766/learn. Show the Python/PLC dropdown and the separate lesson tabs.
2. **Try Python.** Open lesson 1. Read Description. Run `print("Hello, explorer!")`; explain that Run is ungraded. Click Turn in assignment and show the green result banner and saved History entry.
3. **Show a revision.** Change the greeting to `print("Hello!")` and turn it in. Show the retry feedback. The earlier passing completion remains, and both attempts stay in history.
4. **Review as a parent.** Open /parent, select lesson 1 and open the latest attempt. Show the full submitted source and its difference from the prior answer.
5. **Build a PLC rung.** Return home, choose PLC → Ladder Logic, then lesson 46. Open Assignment & history. Drag a normally open SW1 contact onto the new path target; drag the coil into the LAMP output target. Toggle SW1 and show the lamp responding.
6. **Use the operator panel.** Choose Split or I/O Panel. Its SW1 button controls the same tag as the sidebar. Try Undo/Redo, palette filters and zoom. Run scan, then turn in to test all four switch combinations.
7. **Try Structured Text.** Open lesson 50 and enter `LAMP := SW1;`. Toggle the inputs or choose a Run case row, then run a scan. Show the PLC Helper.
8. **Return later.** Stop the sample and start it again; drafts and turn-in history persist.

For a clean presentation, use the original archive on a separate demo installation/project. Do not reset a family’s working database to clear demo history.
